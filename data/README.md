# Data acquisition

This project uses three public data sources. **Raw data are not redistributed in this
repository.** Place the files under `data/` as listed below; `CHECKSUMS.sha256` lists the
expected SHA-256 of the primary inputs.

## 1. Killifish — GSE150318 (NCBI GEO)

- Download the supplementary counts file and series matrix from GEO:
  - `GSE150318_counts.csv.gz` (RNA-seq counts; samples named `FC<k>_<week>w`)
  - `GSE150318_series_matrix.txt.gz` (sample metadata incl. age at death)
- Put both into `data/GSE150318/` (the fish pipeline reads them from
  `code/fish_pipeline/` via the repository root).
- The GFF annotation (`Nfu_20150522.genes_20150922.gff3.gz`) plus
  `gene_annotation.tsv` are used for annotation closure.

## 2. Vaccine — GSE79396 (NCBI GEO)

- Download the series matrix: `GSE79396_series_matrix.txt.gz`
  (log2 RMA values, 54,715 probes × 288 samples; days 0/1/3/7).
- The analysis-specific sample metadata (`samples_all.csv`, including the plate serials
  recovered from CEL file names) is regenerated by the pipeline; a copy of the per-sample
  metadata (no expression values) is provided under `data/metadata/samples_all.csv`
  so the plate mapping can be inspected.
- CEL file names are used only to recover the processing plate serials; the raw CEL files
  themselves are not required.

## 3. Vaccine supplements — Li et al. (2017)

- Subject-level metabolomics, IgG titres, Tfh frequencies and BTM scores come from the
  paper's supplementary tables (doi:10.1016/j.celrep.2017.09.062). Place the extracted
  files under `data/Li2017_suppl/` following the column names used in the pipeline
  (`subject_id`, metabolite features, etc.). Not redistributed here.

## Environment

- R ≥ 4.6 with: `tensorOmics` (GitHub, commit `61afa63`), `mixOmics`, `MASS`, `data.table`,
  `lme4`, `lmerTest`, `sva`, `PLSDAbatch`, `ggplot2`, `patchwork`.
- Python ≥ 3.12 with `numpy`, `pandas`, `scipy`, `scikit-learn`.
